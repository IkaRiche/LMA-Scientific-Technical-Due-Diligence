# 09 — Public evidence navigation

This public repository does not disclose internal repository identities, commit hashes or file paths. Provenance is kept within KOHI BG.

External reviewers may assess the [public claims register](../evidence/CLAIMS_REGISTER.csv), [evidence standards](10_EVIDENCE_STANDARDS.md) and [review protocol](05_REVIEW_PROTOCOL.md). They may observe owner-operated, non-sensitive demonstrations.

No access to protected algorithms, original proofs, code, internal repositories or raw experimental data is offered, including under NDA. Where these are essential, independent verification remains unavailable.
