# 09 — Public source and evidence navigation

This public package intentionally uses **claim IDs and source-category labels**, rather than internal repository URLs, commit hashes, raw evidence filenames or private implementation paths. Internal exact commit pins, immutable protocol versions and underlying raw artifacts are retained within KOHI BG.

For the current Morphic AI source-integrated evidence, read the [Morphic AI scientific screen](13_MORPHIC_AI_REVIEW.md). The source category `MORPHIC_AI` includes separately accepted integrated engineering experiments, accepted experimental causal interventions, and unmerged draft research; these classes must not be conflated. The public package does not expose their underlying source pins.

For the present external focus, start with the [focused claim screen](11_FOCUSED_AUTONOMY_REVIEW.md) and [challenge cards](12_REVIEWER_CHALLENGES.md). Then consult the [public claims register](../evidence/CLAIMS_REGISTER.csv), [evidence standards](10_EVIDENCE_STANDARDS.md) and [review protocol](05_REVIEW_PROTOCOL.md).

The labels `MORPHIC_AI`, `VEIL_RELATIONAL`, `VEIL_ORIGINAL`, `CIVIL_SYNTHETIC` and `TMC` identify **evidence owners/categories**, not externally fetchable pinned sources. Positive reported results and negative controls are both within the internal record.

No access to protected algorithms, original proofs, code, internal repositories or raw experimental data is offered, including under NDA. The published package cannot independently verify results for which such materials are essential. Reviewer findings should say `EVIDENCE_INSUFFICIENT` where appropriate.
